# 한글문서 초안기

실행 주소: https://annewill7-web.github.io/dash/

Gemini API로 공공기관 행정문서 초안을 만들고 HWPX로 저장하는 HTML/CSS/JS 웹앱입니다.

## 파일 구조
- `index.html` — 웹 화면
- `styles.css` — 화면 디자인
- `app.js` — Gemini 호출, 문서 미리보기, HWPX 생성
- `assets/base.0.txt` ~ `assets/base.5.txt` — 검증된 HWPX 템플릿을 Base64로 분할한 자산

## 사용 방법
1. 위 실행 주소에 접속합니다.
2. 화면의 **Gemini API 키** 입력란에 키를 넣고 저장합니다.
3. 문서 유형, 제목, 핵심내용을 입력하고 필요하면 TXT/MD/PDF/DOCX 참고자료를 첨부합니다.
4. **AI 한글문서 초안 생성**을 누릅니다.
5. 결과를 검토한 뒤 **HWPX 저장**을 누릅니다.

## API 키
API 키는 소스코드에 저장하지 않고 브라우저 `sessionStorage`에만 보관합니다. 공개 운영 서비스로 확장할 때는 서버리스 프록시를 두고 키를 환경변수로 관리하는 방식을 권장합니다.

## 문서 시스템
- 보고서·계획안: 요약 → 추진배경 → 주요내용 → 향후계획
- 교육·행사 계획: 추진배경 → 개요 → 세부계획 → 행정사항
- 간결 보고: 요약 → 핵심 현황 → 조치사항 → 향후계획
- 항목 계층: □ → ○ → - → ·

HWPX 다운로드 시 6개 템플릿 조각을 브라우저에서 재결합하고, 검증된 HWPX 패키지의 스타일과 페이지 설정을 유지한 채 `Contents/section0.xml`의 본문을 생성합니다.
